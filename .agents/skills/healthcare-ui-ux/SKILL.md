# Skill: healthcare-ui-ux

## 1. Description & Purpose
Designs accessible, empathetic, and clear healthcare interfaces following MediCompare's design system and patient UX standards.

## 2. Scope & Applicability
Healthcare UI design, typography, color harmony, visual hierarchy, trust indicators, and accessibility.

## 3. When to Use
When creating wireframes, UI components, search layouts, comparison tables, and pharmacy dashboards.

## 4. Required Inputs
- Design system tokens
- User workflows
- Accessibility standards

## 5. Execution Procedure
1. Apply MediCompare design palette: Primary `#059669` (Emerald 600), Dark Green `#064E3B`, Background `#F8FAFC`, Surface `#FFFFFF`, Text `#0F172A`, Secondary `#64748B`.
2. Design search results with immediate clarity: drug name, exact formulation, manufacturer, pack size, price delta, and pharmacy distance.
3. Highlight price savings with transparent context (e.g., "MRP ₹150 | Store Price ₹95 | Save ₹55 (36%)").
4. Place clear regulatory disclaimers and prescription badges on prescription-only formulations.
5. Design mobile-first touch targets (minimum 44x44px) and high-contrast readable typography.

## 6. Safety Constraints & Guardrails
- Never use deceptive dark patterns, false urgency badges ("Only 1 left!"), or misleading price comparisons.
- Strictly respect least-privilege boundaries and privacy mandates.
- Maintain transparent data provenance at all times.

## 7. Expected Outputs & Deliverables
- UI/UX Design Specification
- Component Style Guide
- Accessibility Review

## 8. Validation Checklist
- [ ] Does the UI follow the approved color palette?
- [ ] Are price savings transparently explained?
- [ ] Are prescription warnings clearly visible?
